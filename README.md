# 🩸 O Analista — Arquivos de Vilões

Projeto desenvolvido durante o curso de Front-End, com o objetivo de praticar estruturação de páginas web, estilização e componentes utilizando Bootstrap.

## 🕵️ Sobre o projeto

"O Analista" é uma página temática criada como um dossiê fictício sobre um personagem misterioso, apresentando sua história, características, poderes, fraquezas e últimos avistamentos.

A proposta visual utiliza uma estética sombria e cinematográfica, combinando tons escuros com detalhes em vermelho para criar uma atmosfera de suspense.

## ⚙️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## 📌 Conteúdo

- Ficha técnica do personagem
- Poderes e fraquezas
- História e características
- Últimos avistamentos
- Design responsivo

## 🎯 Objetivo

Praticar conceitos de desenvolvimento Front-End, incluindo:

- Estruturação semântica com HTML
- Estilização com CSS
- Utilização do Bootstrap
- Responsividade
- Organização de conteúdo
- Criação de uma identidade visual para uma página web
